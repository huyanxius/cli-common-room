# cli-common-room

在一个终端窗口里与 Claude Code、Codex 和 AGY 共同工作。原生程序负责认证、模型、工具与记忆，Common Room 提供共享消息流、命令菜单和会话恢复。审批支持取决于各原生协议，AGY 的限制见下文。

## 启动

安装 Node.js 22.14+（22.x）或 24.x，并确保本机 `codex`、`claude` 可用且已配置。

```sh
npm ci
npm run build
npm link
cd /path/to/your/project
room
```

不安装全局命令时，在仓库运行 `npm start`，或在目标工作目录运行 `/path/to/cli-common-room/bin/common-room.mjs`。`room` 以当前目录作为工作区，旧命令 `common-room` 保留兼容，不覆盖 `codex` 或 `claude`。

```sh
room --help
room --status
room --check-codex
room --codex-bin /path/to/codex --claude-bin /path/to/claude
```

首次进入配置引导，可用上下键选择成员、检测程序、修改程序路径及登录；之后用 `/setup` 或 `room --setup` 重新打开。`/login claude`、`/login codex` 直达成员配置。登录在原生 CLI 的浏览器授权流程中完成，验证码仅在内存中转交，不进入聊天历史。Esc 取消登录并回到引导。

Claude 初次引导默认选择本机登录，避免启动环境中的 `CLAUDE_CODE_OAUTH_TOKEN` 遮蔽本机账号和订阅额度；可以明确切换为“沿用启动环境认证”。本机登录模式只在 Claude 子进程移除环境认证覆盖，不修改系统环境或原生凭据。其他配置继承当前环境，包括 `CODEX_HOME`、`CLAUDE_CONFIG_DIR`。Shell alias 不会自动变成子进程配置；alias 中的环境变量应在启动前导出，程序路径使用上面的参数。SDK 调用 PATH 中的本机 Claude Code，不使用 SDK 随包附带的另一份 CLI。没有免审批、禁用工具或替换认证的默认开关。

## 使用

引导中选择 Codex、Claude Code 或双方；下次启动沿用选择。配置只保存程序路径、认证来源和引导偏好，按原生配置目录隔离，不保存凭据。未安装、未登录和连接失败可留在引导中重试。

| 操作 | 命令或按键 |
| --- | --- |
| 选择接收者 | `@` 弹出成员菜单，Enter/Tab 补全后保留草稿；支持 `@codex @agy 问题`、`@all` 和 `/to` |
| 模型、思考强度 | `/model`、`/effort` 打开原生选项列表，↑↓ 选择、Enter 确认、Esc 返回 |
| 浏览命令 | 输入 `/`；上下选择，Tab 补全 |
| 发送、换行 | Enter；Alt+Enter |
| 输入历史、编辑 | 上下键；左右、Home、End、Ctrl+A/E/U/K |
| 滚动消息 | 鼠标滚轮、Page Up / Page Down；Ctrl+End 回到底部 |
| 工具详情 | Ctrl+T 展开或收起长命令输出 |
| 排队 | 输出中 Enter 排队，固定提交时的接收者；`/queue` 用箭头选择继续、撤回或清空 |
| 停止当前任务 | Esc / Ctrl+C 调用原生取消；空闲时 Ctrl+C 退出 |
| 新房间 | `/new` 或 `/clear`，重建原生上下文 |
| 仅清空可见消息 | `/screen-clear` |
| 恢复房间 | `/resume` 打开历史列表，↑↓ 选择、Enter 恢复、Esc 返回 |
| 查看完整状态、差异 | `/status`、`/diff` |
| 退出 | `/exit` 或空闲时 Ctrl+C |

打断暂停尚未派发的队列，但仍可直接发送新指令；`/queue` 明确继续旧队列。双方模式停止后不启动尚未执行的另一方。停止超时关闭原生连接并标记结果未知，不自动重发。

多行粘贴不会自动发送。可以在一条消息中多次点名，按出现顺序去重；用空白或中文标点分隔的正文点名也有效，邮箱和反引号代码中的名字不触发派发。未点名时沿用当前接收者，`@all` 选择全部三位成员。命令只作用于当前单个成员。被点名者收到同一份讨论快照，依次执行，下一轮才接收其他成员的本轮回答。排队时固定接收者，后续选择不改变已入队消息。

## AGY 接入

安装并在原生 `agy` 完成登录后，用 `/setup` 选择 AGY，或输入 `@agy`。程序路径可通过 `room --agy-bin /path/to/agy` 配置。AGY 使用低饱和绿色标识，正文沿用终端原色。

适配器使用本机 `--input-format stream-json --output-format stream-json`，沿用原生认证、权限、工具、规则和记忆；`--conversation` 恢复必须返回相同会话 ID。文本、工具状态和 token 用量显示在群聊中。`/model`、`/effort`、`/usage` 等为原生只读报告，不支持在 room 中修改 AGY 模型或权限；订阅报告保留原文，不推测额度进度条。

AGY 1.2.4 的无界面协议不提供审批和提问回传：需要确认的工具由原生拒绝，room 不添加免审批参数。原生配置已有的允许规则仍有效。出现拒绝操作时不把轮次标为完整成功；超时、断线或未确认停止保留交付未知状态，不自动重发。Esc 关闭本应用启动的原生连接，不能保证撤销已经发生的工具操作。

已验证原生固定回复、文件读取事件和恢复后的口令记忆；读取轮次曾超时，恢复轮次同时报告拒绝操作，未将其当成完整成功。自动测试覆盖连续会话、恢复 ID 校验、取消、拒绝、超时和多成员终端派发。真实交互审批不在此协议的支持范围内。

背景和正文继承终端主题，Codex 用紫色、Claude 用橙色强调。顶部紧凑显示真实模型、工作目录、Git 分支/工作树、上下文和订阅进度条，`/status` 展示详细 token、原生会话 ID、程序路径和认证来源。连接与执行用动态指示和耗时反馈，空闲停止动画；按行更新画面。用户、两位成员和工具记录分层显示，工具记录按原生 ID 更新完成状态。订阅限额按原生返回的实际窗口展示，明确标注**已用**百分比和重置时间；没有数据时显示未提供，不填零。不同模型额度桶分别标名，不能把某一模型的 5h 额度当成整个订阅的额度。Claude 额度与聊天使用同一会话、同一认证；连接时查询，轮次结束后按至少 30 秒间隔刷新，`/usage` 可主动刷新。订阅、额外用量启用状态分别显示；API 等价估算不是实际扣费凭据。

## 原生命令

Claude 命令目录来自本机 CLI 的初始化响应，包括已加载的自定义 skills。`/model`、`/mcp`、`/usage` 使用结构化控制接口；目录中的其他命令在同一原生会话执行，文本与工具事件回到统一消息区。

Codex 使用 app-server 对应接口：`/model`、`/effort`、`/usage`、`/skills`、`/mcp`、`/compact`、`/rename`、`/review`、`/permissions`、`/fast`、`/plan`、`/apps`、`/hooks`。已加载 skills 加入命令菜单，也可以用 `$名称` 调用。`/permissions` 修改前需要明确确认；`/compact` 等待原生完成事件。

共同入口保留 `/help`、`/status`、`/to`、`/new`、`/clear`、`/screen-clear`、`/resume`、`/diff`、`/exit`。其中 `/resume` 恢复 Common Room 自己的房间，不导入其他入口的私人历史。原生终端专属、宿主注入或当前协议未提供的命令不会自动变成模型提示词，也不会跳转到原生 CLI 冒充完成；原生报告不支持时直接显示错误。命令目录可用不等于其每一种交互形式都已验证。

## 保存与错误处理

房间保存在 `${XDG_STATE_HOME:-~/.local/state}/common-room/`，按工作目录与原生配置目录隔离。目录权限 700、记录权限 600，包含本应用的群消息、原生会话引用和交付位置，不复制认证或原生会话数据库。

原子保存发生在发送前与收到原生结果后。异常中断留下的交付状态标为未知，恢复后阻止自动重发。文件锁防止两个 Common Room 入口同时恢复同一记录。取消不回滚已发生的工具操作；本应用无法阻止外部原生终端直接操作同一线程。

授权没有默认允许项，先用上下键选择再 Enter 确认，也可输入编号；提问在窗口内回答，敏感输入掩码显示。未识别的协议交互明确失败，不自动批准。Claude 的复杂多选提问目前通过文本填写多个选项；终端专用对话框仍取决于安装版本的程序化支持。

## 验证与开发

```sh
npm run typecheck
npm test
```

测试使用隔离协议夹具与 PTY，不调用真实模型或个人配置。真实验证使用 Terminal.app，不截图：双方同屏回复、Claude `/effort` 与 `/context`、双方关闭恢复后的口令记忆、Codex 真实文件读取。审批拒绝、粘贴、停止与过期保护通过协议或 PTY 测试，不将它们冒称为真实模型授权验收。

本轮实际验证：Terminal.app 中本机登录、5h/7d 额度显示；Claude 同一原生会话取消后继续回复；原生模型与思考强度切换。浏览器登录的用户授权步骤需本人完成，自动测试覆盖登录进程成功、失败、取消与验证码转交。

实测版本：Codex CLI `0.154.0-alpha.6.2`、Claude Code `2.1.272`（旧版 `2.1.241` 也完成额度对比），Claude SDK 锁定 `0.3.273`。订阅用量接口具有版本差异；Claude 结构化用量接口当前属于实验接口。程序不自动升级原生 CLI，不自动重试可能已执行的任务。Ghostty 和其他终端的实测后置。
